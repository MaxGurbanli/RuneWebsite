Update v1.14

On March 10th, 2022


This is a massive economy-focused update bringing a lot of balance changes and bug fixes to make the economy system easier and more fun to use.

Utility: a new category to help you out
That's right, a new command category has arrived! The Utility category will be home to commands to help you out in various situations.

It is currently home to 3 commands:
- !!buildembed (new)
- !!avatar (moved from Information)
- !!serveravatar (moved from Information)

The new !!buildembed command is an easy way to create your own Discord embed using Rune. It will also be improved with more options when Discord makes more features with modals available to bots.

Economy balance changes are finally here!
With these changes I focused on making Rune's economy system more engaging with commands and ways to earn money.

- hunt, dig, fish cooldowns reduced 60m -> 30m
- hunt, dig, fish now award guranteed 2-9 coins (removed option to fail)
- search cooldown reduced 25m -> 15m
- search reward changed (2-5 coins -> 1-6 coins)
- Removed 5% tax for gifting coins
- Slightly lowered sell prices of all shop items to discourage use of inventory to store coins
- Significantly lowered bank level upgrade costs

The costs to upgrade your bank level are now the following:
Level 1: 100 rc
Level 2: 100 rc
Level 3: 100 rc
Level 4: 200 rc
Level 5: 200 rc
Level 6: 200 rc
Level 7: 200 rc
Level 8: 200 rc
Level 9: 500 rc
Level 10: 1000 rc

Gift command smart number parsing
Added smart number parsing to the gift command for other ways of representing numbers. For example 1k 1_000 1,000 are all equal to 1000.

Bug fixes
Not too many this time around. Phew.

- Fixed the heist emoji task not failing properly if done incorrectly
- Fixed smart number parsing for bets

That's all for now! A lot of this comes from your feedback - feel free to share your thoughts in our Discord server.
