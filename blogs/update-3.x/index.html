Update v3.x Thread

Last updated July 4, 2026.


This is an update thread for change notes of all v3.x updates. This blog is updated when a new update is released.

Update v3.4.8

Economy

  • Recovered some coins, bank balances, and items that had become stuck in duplicate profiles
  • Your profile is now protected against this duplication happening again

Performance

  • Commands that read server or profile data are now noticeably faster and put far less load on the database
  • Improved stability during database hiccups so the bot stays responsive instead of hanging

Server Settings

  • Changes to your server settings now take effect instantly: /logchannel (all types), /ignorechannel, /settings deletescams, /settings autorole, /settings prefix

Update v3.4.7

Improvements

  • /inventory has received a redesign to improve how your ores, fish, wood, and items are displayed

Update v3.4.6

Changes

  • Rune will no longer count getting pinged as a command prefix, i.e. you can no longer use "@Rune#5846 help" to run /help

Bug Fix v3.4.5

Fixes

  • Added safeguards to some slash commands that perform long operations to prevent the command timing out instead of thinking and responding later: /leaderboard, /dadjoke, /trivia, /serverinfo, /achievements, /balance view, /cooldowns, /business list

Update v3.4.4

Removal

  • Removed /advice (the 3rd party provider has discontinued their API)

Bug Fix v3.4.3

Fixes

  • Fixed /shop buy and /shop sell autocomplete no working due to surpassing 25 items
  • Fixed /business hire contract offers not being sent

Bug Fix v3.4.2

Fixes

  • Fixed /inventory use still relying on the old item system causing issues when trying to use the new (unusable) nautical items

Bug Fix v3.4.1

Fixes

  • Fixed /inventory not working when you had no ores

Update v3.4 - The Nautical Update

New content

  • New /cooldowns command will show all of your current Economy cooldowns
  • New shop items: Rope, Compass, Sailcloth
  • New craftable items: Raft, Fishing Net, Treasure Map
  • New findable items: Map Fragment, Gold
  • New catchable fish: Trout, Salmon, Tuna, Swordfish, Anglerfish, Shark
  • /fish has been expanded, the new nautical items will improve the quality and quantity of fish you are able to catch!

Improvements

  • /inventory has been revamped and now houses your Ores, Wood and Fish
  • Selling Ores and Wood is now done using the buttons under your inventory
  • The /ores and /wood commands have been removed
  • /business hire will now send contract offers within the same channel rather than DMing the employee to prevent abuse

  • New buyable Battery item
  • New findable Rune Shard item

Changes

  • Added cooldown to /rob

Update v3.0

Revamped Banking system

  • Open a bank account using /openaccount (name).
  • You can open up to 3 bank accounts in a bank!
  • View your bank accounts through /balance.
  • Currently the only bank is Rune Inc, player made banks are planned.
  • Deposit and withdraw asks you to select a bank account if more than 1 is open.
  • Banks hold cash, reserves, liabilities/assets and balances like real banks!
     --> Use /bankinfo to view these values.

Revamped Business system

  • Start a business using /business create [name], then pick a business type.
  • Hire employees with /business hire [@user].
  • Hired employees (and the owner) can work at the business through /business list.
  • Fire employees with /business fire [@user].
  • Complete minigames once a day to earn coins!
  • New businesses: Mining Operation and Lumber Mill!

Achievements

  • Help you learn the game!
  • View your progress using /achievements.

Other changes

  • Wiped wallet and bank account balances
  • Replaced medkit and bandages with /pet heal (+15 health for 10 Rune Coins)
  • /pay now uses smart amount processing (1,000 | 1_000 | 1k are valid inputs)
  • /shop sell now has an optional amount parameter with smart processing
  • Trivia cooldown increased to 15s to prevent API ratelimits
  • Performance improvements: Shop items are now stored locally, faster load times
  • Removed no longer supported /compare - will return in the future!
  • Removed unpopular Runeordle mini-game - no one will miss it.
